# ADR-002: Ring Buffer API — BPF ring buffer vs perf buffer

## Context
Two distinct APIs exist in the Linux kernel for shipping event telemetry from kernel-space eBPF programs to userspace processes:
1. **BPF Perf Buffer** (`BPF_MAP_TYPE_PERF_EVENT_ARRAY`)
2. **BPF Ring Buffer** (`BPF_MAP_TYPE_RINGBUF`)

## Decision
We chose to enforce **BPF Ring Buffer** as the exclusive kernel-to-userspace transport mechanism.

## Consequences
- Requires Linux kernel version ≥ 5.8 (which introduced the Ringbuf helper functions).
- High-efficiency lockless single-producer multi-consumer buffer allocation.
- Avoids the memory fragmentation issues associated with per-CPU perf buffers, ensuring we never drop sound-state telemetry when under memory bounds.
