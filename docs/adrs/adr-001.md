# ADR-001: eBPF Library — Aya (Rust-native) vs libbpf (C bindings)

## Context
We need to load and manage eBPF programs from userspace inside our Rust conductor.
Two options exist:
1. **Aya**: Pure-Rust eBPF loader library (no libbpf dependency).
2. **libbpf-sys**: Direct C bindings to standard libbpf.

## Decision
We chose **Aya** (pure Rust) to integrate eBPF programs.

## Consequences
- **Pros**:
  - Zero C runtime library dependencies.
  - Native Tokio/async support.
  - Superior compile-time type safety for map loading and sharing.
- **Cons**:
  - Aya is pre-1.0 and has API volatility.
  - Require Compile Once, Run Everywhere (CO-RE) via BTF for compatibility.
