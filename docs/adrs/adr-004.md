# ADR-004: OSC Protocol — UDP vs TCP

## Context
Open Sound Control (OSC) payloads can be shipped over either UDP or TCP network layers.

## Decision
We chose **UDP only** for our real-time audio/visual dispatcher.

## Consequences
- Lower latency and lower resource overhead.
- Fire-and-forget alignment: missing one package is acceptable as the next window (50ms) will push newer state instantly.
- Avoids the connection management, keepalives, and latency buffers required by TCP socket streams.
