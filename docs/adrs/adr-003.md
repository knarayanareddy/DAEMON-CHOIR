# ADR-003: Control API Protocol — REST/HTTP vs Unix Socket vs gRPC

## Context
We need a protocol for the terminal UI and potential external clients to query live metrics, view probe statuses, reload configuration, or trigger privacy wipes.

## Decision
We selected **REST/HTTP over TCP Loopback** (using Axum) as the communication protocol.

## Consequences
- Highly accessible from any local tool (curl, browser, Python/Node scripts).
- Avoids the setup and tooling overhead of gRPC.
- Safe local boundaries by enforcing `127.0.0.1` binding.
- Control API thread failure domain is strictly isolated from the high-priority audio telemetry loop.
